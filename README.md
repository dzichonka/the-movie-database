# 🎬 RS School React Course Project

## 📚 About the Course

This project is part of the **RS School React Course (2026)** — an intensive program designed for students who have successfully completed Stage #2 or already have solid frontend experience.

The course covers modern React development from fundamentals to advanced topics, including:

- React fundamentals & components
- Hooks & routing
- State management (Redux, Zustand)
- API handling (RTK Query, TanStack Query)
- Forms & portals
- Performance optimization
- Server-side rendering (Next.js)

⏳ **Duration:** 11 weeks
🕒 **Workload:** 20–40 hours per week

🔗 [Course description](https://github.com/rolling-scopes-school/tasks/blob/master/react/README.md)
🔗 [RS School](https://rs.school/)

## 🚀 About This Project

This project is a **movie discovery web application** inspired by:

🔗 https://www.themoviedb.org/

### 🎯 Goal

Build a modern React application that allows users to:

- Browse popular movies
- Search for films
- View detailed movie information
- Interact with a clean and responsive UI
- Work with real API data

### 🛠 Planned Tech Stack

- React + TypeScript
- Vite
- React Router
- State management (Redux Toolkit / Zustand)
- Data fetching (RTK Query or TanStack Query)
- CSS / SCSS (or styled solutions)
- Testing (Jest / React Testing Library)
